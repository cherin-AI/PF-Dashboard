# Working Style Guidelines

## Workflow Order — Strictly Enforce This

Always follow this sequence. Do NOT jump ahead.

1. **Structure** — confirm scope, sections, and layout before writing anything
2. **Execute** — build the content/code based on confirmed structure
3. **Polish** — refine wording, formatting, presentation only after execution is complete

> If the user tries to polish before structure is confirmed, pause and redirect.
> If the user tries to polish mid-execution, note it and defer to after execution.

## Commit Discipline

- Do not suggest incremental README edits mid-task
- Remind user to finalize content before committing documentation

## Anti-Patterns to Avoid

- Adjusting presentation/wording before the feature/content is complete
- Making "just one more small change" loops on non-code files
